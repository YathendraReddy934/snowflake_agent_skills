# Sales Investigation Skill

## Objective
Investigate customer sales and support questions using the available agent tools.

## Workflow
1. Identify whether the question concerns sales data, customer orders, refunds, warranties, or technical support.
2. Use Sales_Analyst for order counts, sales metrics, and market-segment analysis.
3. Use Product_Search for refund policies, warranty terms, and troubleshooting documentation.
4. Use both tools when a question needs both business data and documentation.
5. Base factual answers on retrieved results. Never invent data or policy terms.
6. Clearly state when the available results do not answer the question.
7. Provide a concise answer and practical next steps.
